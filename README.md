# ahvauto TS 版（HentaiVerse 自动战斗）

原 dodying `[HV]AutoAttack`（v2.88）的 TypeScript＋Svelte 重写版：
配置界面全新实现，战斗内核逐行对照原版移植，另修了原版几个陈年 bug。

## 安装

1. 浏览器装 Violentmonkey（或 Tampermonkey），**禁用旧版脚本**（两个不能同时跑）。
2. 把 `dist/ahvauto.user.js` 拖进脚本管理器安装并启用。
3. 刷新 hentaiverse 页面。沿用旧版配置的，点面板“关于→导入旧配置”（含攻击模式、权重、全部条件）。

> 开发联调装 dev 版（见 `docs/DEV.md`），日常使用装 `dist` 版。

## 快速开始

1. 点页面右上 `hvAA` 悬浮钮打开面板（14 个选项页，dev 版显示 `hvAA·dev`）。
2. 主要选项：选**攻击模式**（留空 -1＝未配置拦截态，0 物理＝战士，1-6＝法师，玩法区别见 `docs/CLASSES.md`）。
3. 按需开功能：物品、Buff/Debuff、卷轴、魔药、警报、掉落监测、数据记录。
4. 条件填表达式（如 `hp < 30 or mp > 50`），空＝恒成立，写错即时标红。
5. 关面板，战斗页面会自动打；战斗外页面会按配置打竞技场/遭遇战。

## 功能一览

- **战斗循环**：宝石→物品→防御→卷轴→Channel→Buff→魔药→Imperil→Debuff→出手，每回合只做一个动作；面板实时显示本轮决策历史（最新在上，带序号）。
- **集火**：按血量＋Debuff 权重自动选目标，死怪永不选中。
- **保底**：血量跌破阈值（默认 15%）自动暂停＋告警；误操作可随时点暂停按钮。
- **战斗外**：闲置竞技场（自动排队开打）、自动遭遇战、体力恢复、答题只报警不代答。
- **数据**：伤害/承伤/治疗/击杀/掉落按整局记录（带战斗类型＋胜负），数据记录页可查、可点详情、可导出 CSV。

## 安全须知

- 新旧配置完全隔离（`ahvauto-*` vs `hvAA-*`）：**旧配置只读不写**，可随时切回旧版。
- 数据不向后兼容：数据统计/战斗记录/掉落等升级会清零重记（旧数据不迁移）；只有配置格式向后兼容，启动时自动迁移。
- 战败不自动复活，复活由你手动决定。
- 小马答题只报警、不自动提交（官方红线）。
- 遇到连续失败会自动暂停/重载并记日志，详见面板“关于→运行日志”。
