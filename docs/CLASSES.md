# 职业玩法对照（战士 / 法师）

> 本文档是**配置层**的既定事实，原脚本无显式的战士/法师概念（代码只认两条正交轴，
> 见下），混搭不会被阻止。这里记录“怎么配才对”，改玩法先改本文。

## 攻击模式 → 职业（已确定，不许反转）

| attackStatus                            | 含义               | 职业     |
| --------------------------------------- | ------------------ | -------- |
| 0 物理 / Physical                       | 普攻＋武器         | **战士** |
| 1 火 / 2 冰 / 3 雷 / 4 风 / 5 圣 / 6 暗 | 按系魔法＋按系魔药 | **法师** |

## 战士（物理模式）

- **Spirit Stance 是 +100% 物理伤害的姿态增益，战士一般常开它吃增伤**。
  另经实测：Spirit 关闭时，武器按钮（OFC/FRD/T 系）会被服务器置灰
  （`opacity: 0.5`），脚本的 `spiritOn` 门与该状态一致——不开 Spirit，
  武器既无增伤也点不动。 maintainer 如要放开此门，需先验证灰态点击
  是否真能发包（2026-09 实测为灰，不建议放开）。
- **武器技能**：OFC（1111，需 8 OC）/ FRD（1101，需 4 OC）/
  T3/T2/T1（`2<fightingStyle>0<阶>`，各需 2 OC）＋各自条件＋可选 OTOS（一回合一次勾选）。
- `fightingStyle` 1/2/3/4/5 只决定 T 系技能 ID
  （1 二天一流 / 2 单手 / 3 双手 / 4 双持 / 5 法杖）；
  `fightingStyle==2`（单手）＋T3 独占 Merciful Blow（目标血 <25% 且流血则转火）。
- 物理模式**跳过**：高/中/低阶魔法、魔药（`attackStatus!==0` 门）。
- 普攻（`#mkey_` 集火目标）有可点活怪时兜底，否则返回 `none`。

## 法师（1-6 模式）

- **Spirit Stance 保持关闭**：武器技能与法师无关，不配开关条件。
- **输出链**：武器链优先（能放则覆盖），其次高阶魔法（`1<系>3`，需 highSkillCondition）→ 中阶（`1<系>2`，
  需 middleSkillCondition）→ 低阶（`1<系>1`，无条件），技能可用性看是否变灰
  （CD/缺蓝）。法师 Spirit 关故武器自动跳过，最后普攻兜底。
- **奥术集成 AF（432）是法师伤害增益，法师一般常开**（放进 Buff 顺序，
  缺失即补；Channeling 窗口 1MP＋150% 伤害时优先补）。它在原脚本里只是
  9 buff 之一，无特殊逻辑——“必须开”是玩法惯例，不是代码强制。
- **魔药**：按攻击模式查表（火 12101 / 冰 12201 / 雷 12301 / 风 12401 /
  圣 12501 / 暗 12601），缺失即吃。
- 当前暗法配置实例：`attackStatus=6`，buff 顺序 `[SL,Ab,AF,Re]`，
  卷轴 `Pr/Sw/Li/Sh/Ab`，魔药开，`turnOnSS/turnOffSS` 全关。

## 两职业共用（与模式无关）

宝石（阈值 hp1/mp1/sp1）→ 物品（用户顺序＋独立条件）→ Defend →
卷轴（`roundTypes` 门＋仅 `scrollFirst` 勾选时认 `_scroll` 后缀规则）→ Channel 三段 →
Buff（含药水/花瓶/口香糖）→ 魔药（法师）→ 全员 Imperil →
单体 Debuff → 出手链。集火权重、掉落/数据记录与职业无关。

留空（-1）＝未配置拦截态，不开打。
